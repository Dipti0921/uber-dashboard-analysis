# Uber Dataset Analysis Dashboard

## Project Overview
Built an interactive Power BI dashboard using a public Uber dataset to analyze ride bookings, revenue, and travel patterns across different time periods.

The project focuses on identifying booking trends, customer behavior, revenue performance, and vehicle-wise analysis through interactive visualizations and KPI metrics.


## Tools & Technologies Used
- Power BI
- Power Query
- DAX
- Data Cleaning
- Data Modeling


## Key Features
- Completed vs Cancelled Booking Analysis
- Revenue Analysis Dashboard
- Vehicle Type Performance Tracking
- Customer & Driver Rating Insights
- Monthly & Quarterly Trend Analysis
- Interactive KPI Cards and Filters


## Data Analysis Process
- Cleaned and transformed raw dataset using Power Query
- Built data models and relationships
- Created DAX measures for business metrics
- Designed interactive dashboard visualizations
- Analyzed travel and booking patterns


## Key Insights
- Identified peak booking periods and ride demand trends
- Compared performance across vehicle categories
- Analyzed completed and cancelled bookings
- Evaluated customer and driver ratings
- Highlighted revenue patterns across time periods
